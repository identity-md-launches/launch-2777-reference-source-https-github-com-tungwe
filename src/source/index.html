Chain activity is read only

IMD's current Intake is monitored on Ethereum mainnet (chain 1). SqueekCore is monitored on Sepolia testnet (chain 11155111). The watcher checks deployment code, emitter, canonical block hashes, receipts and ABI decoding. It reads 3 blocks behind the Ethereum head for IMD and 12 blocks behind for Squeekchain. It begins at a confirmed baseline without celebrating old history. Public providers can fail or block requests; the interface reports unavailable and retries with backoff.

Completed Squeek blocks are derived from cumulativeBlockUnits divided by 1,000,000,000. A settlement is not a wallet payout. An IMD request is not a completed job. Wheel telemetry is a separate, unconfirmed public API reading. All 12 animation rehearsals are labelled simulated and cannot write chain history or care rewards.

Free AI on your device

AI starts preparing only after Send. Compatible WebGPU devices use pinned Qwen3-0.6B MLC q4f16 via WebLLM 0.2.87 (about 360 MB). Compatibility mode uses Transformers.js 3.8.1 and pinned Qwen3-0.6B ONNX q8 (about 650 MB). Existing complete caches are reused. Runtime libraries are fetched from pinned public CDN versions and the MLC binary from a pinned GitHub commit; weights come from pinned Hugging Face revisions. Downloads require a network connection.

There is no sign-in, API bill, inference server or connection to the creator's computer. Prompts and replies remain on your device. CDN/model hosts receive download requests, not chat. Chat disappears on reload or Clear. Stop terminates its worker; an explicit compatibility retry follows GPU failures. Some devices lack memory or graphics support; small models can make mistakes. Feeding and play remain available.

Saved progress and accessibility

Existing saves, five growth stages, accessories, care games and elapsed-time growth are preserved. New chain cursors, card and expression preferences are separate browser settings. Chain celebrations and invitation touches cannot add care points or speed growth. Clearing browser storage removes local saves; no cross-device service is provided. Food can be dragged to the visible mouth target or activated with Tab and Enter. Canvas keyboard shortcuts provide touch/turn equivalents. Reduced motion uses static expressive poses.
