如何讀懂這個儀表板？

即時狀態每 15 秒讀取；統計及結算每 60 秒讀取。切換到其他分頁時暫停請求。連線失敗會逐步延長重試時間；保留的舊資料會標示為過期，不會用零取代未知資料。

跑輪活動、Oracle 驗證、Ethereum 結算、SQK 發行是不同階段，數字不一定同步。金額以整數處理，畫面小數採截取顯示。示範模式使用虛構範例，不會送出 API 請求。
